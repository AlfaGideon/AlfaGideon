# 🤖 Настройка и запуск Telegram бота - АТТЕСТАТ БЕЗ РЕМНЯ

## Что создано

Полностью функциональный Telegram бот для образовательной платформы "АТТЕСТАТ БЕЗ РЕМНЯ" со всеми возможностями веб-приложения:

### ✅ Реализованные функции

**Для студентов:**
- Просмотр доступных уроков
- Доступ к играм (память слов, грамматика, произношение, культурная викторина, Эрудит)
- Отслеживание достижений и прогресса
- Таблица лидеров
- Профиль и настройки

**For преподавателей:**
- Управление студентами
- Быстрый доступ к созданию контента
- Управление материалами
- Игра Эрудит
- Аналитика студентов

**Для администраторов:**
- Системная статистика
- Управление пользователями
- Управление контентом
- Системные настройки
- Логи действий

## Как запустить бота

### 1. Получите токен бота

1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Сохраните полученный токен

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
DATABASE_URL=postgresql://username:password@localhost:5432/russian_mentor
PORT=5000
NODE_ENV=development
```

### 3. Запуск

```bash
# Используйте встроенный скрипт
./run-bot.sh

# Или напрямую через npm
npm run start:bot

# Для разработки с автоперезапуском
npm run dev:bot
```

## Команды бота

Команды автоматически устанавливаются в меню Telegram при запуске бота:

- `/start` - 🚀 Начать работу (регистрация/авторизация)
- `/menu` - 📋 Показать главное меню
- `/reset` - 🔄 Сбросить аккаунт и выбрать роль заново
- `/help` - ❓ Показать справку по командам

**Примечание:** После первого запуска бота команды появятся в квадратном меню (рядом со скрепкой) в Telegram.

## Архитектура

- **Интеграция с базой данных**: Бот использует ту же базу данных, что и веб-приложение
- **Роли пользователей**: Автоматическое определение роли и показ соответствующего меню
- **Аутентификация**: По Telegram ID пользователя
- **Умные переходы**: Сложные задачи направляют в веб-приложение

## Примеры использования

### Студент
1. Отправляет `/start`
2. Видит меню: Уроки, Игры, Достижения, Прогресс, Лидеры, Настройки
3. Выбирает "Уроки" → видит список доступных уроков
4. Выбирает "Прогресс" → видит уровень, опыт, стрик, завершенные уроки

### Преподаватель  
1. Отправляет `/start`
2. Видит меню: Студенты, Создать урок, Создать квиз, Материалы, Эрудит, Аналитика
3. Выбирает "Аналитика" → получает статистику студентов

### Администратор
1. Отправляет `/start`  
2. Видит меню: Управление пользователями, Статистика системы, Управление контентом
3. Выбирает "Статистика системы" → видит количество пользователей, контента, активных пользователей

## Безопасность

- Аутентификация через Telegram ID
