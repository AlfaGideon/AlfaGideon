Полная схема вкладок для всех ЛК  
*(Ученик, Репетитор, Родитель, Админ)*  

---

### 1. Личный кабинет Ученика  
Вкладки:  
1. Главная  
   - Ближайшие занятия (виджет).  
   - Последние оценки.  
   - Рекомендуемые материалы.  

2. Расписание  
   - Календарь с уроками (день/неделя/месяц).  
   - Запись на групповые занятия.  
   - История посещений.  

3. Задания  
   - Активные задания (сроки, статус).  
   - Архив выполненных работ.  
   - Загрузка файлов (PDF, аудио, видео).  

4. Прогресс  
   - Графики успеваемости по предметам.  
   - Рейтинг среди группы.  
   - Рекомендации от репетитора.  

5. Видеоконференции  
   - Предстоящие сессии.  
   - Доступ к интерактивной доске.  
   - Записи прошедших уроков.  

6. Чат  
   - Диалоги с репетитором.  
   - Групповые чаты (для курсов).  
   - Уведомления о новых сообщениях.  

7. Профиль  
   - Личные данные.  
   - Настройка тем (цвета, анимации).  
   - Привязка соцсетей.  

8. Оплата  
   - Текущие подписки.  
   - История платежей.  
   - Пополнение баланса (интеграция с Т-банком).  

---

### 2. Личный кабинет Репетитора  
Вкладки:  
1. Главная  
   - Ближайшие уроки.  
   - Уведомления о новых учениках.  
   - Финансовая сводка.  

2. Ученики  
   - Список учеников (фильтры по предметам).  
   - Прогресс каждого (графики, оценки).  
   - Добавление/удаление из групп.  

3. Расписание  
   - Настройка слотов для занятий.  
   - Импорт/экспорт в Google Calendar.  
   - Автоматические напоминания.  

4. Материалы  
   - Библиотека уроков (PDF, видео).  
   - Шаблоны заданий.  
   - Модерация контента (для групповых курсов).  

5. Финансы  
   - Выставление счетов.  
   - Статистика доходов.  
   - Запрос выплат на карту.  

6. Видеоконференции  
   - Создание групповых сессий.  
   - Настройка прав участников (микрофон/демонстрация экрана).  
   - Доступ к записям уроков.  

7. Аналитика  
   - Конверсия учеников.  
   - Рейтинг по отзывам.  
   - Загрузка отчетов в Excel.  

8. Профиль  
   - Портфолио (сертификаты, опыт).  
   - Настройка тарифов.  
   - Кастомизация тем (анимированные фоны).  

---

### 3. Личный кабинет Родителя  
Вкладки:  
1. Главная  
   - Успеваемость ребенка (сводка).  
   - Предстоящие оплаты.  
   - Новые сообщения от репетиторов.  

2. Дети  
   - Привязка аккаунтов детей.  
   - Переключение между профилями.  
   - Настройка доступа к курсам.  

3. Отчеты  
   - Еженедельная статистика.  
   - Сравнение с предыдущими периодами.  
   - PDF-отчеты для школы.  

4. Оплата  
   - Автоплатежи за занятия.  
   - История транзакций.  
   - Возврат средств.  

5. Чат  
   - Общение с репетиторами.  
   - Участие в родительских чатах.  
   - Уведомления о важных событиях.  

6. Настройки  
   - Ограничение доступа к материалам.  
   - Управление уведомлениями.  
   - Смена пароля.  

---

### 4. Личный кабинет Администратора  
Вкладки:  
1. Пользователи  
   - Поиск по ролям/фильтрам.  
   - Блокировка/разблокировка.  
   - Назначение прав доступа.  

2. Контент  
   - Модерация материалов.  
   - Удаление нарушающих правил тем.  
   - Управление галереей шаблонов.  

3. Финансы  
   - Общая статистика платежей.  
   - Настройка комиссий.  
   - Экспорт данных в налоговую.  

4. Система  
   - Интеграция с Т-банком.  
   - Логи ошибок.  
   - Резервное копирование.  

5. Аналитика  
   - Активность пользователей (DAU/MAU).  
   - Конверсия бесплатных пробных периодов.  
   - Heatmap использования функций.  

6. Техподдержка  
   - Обращения пользователей.  
   - Шаблоны ответов.  
   - История решенных кейсов.  

---
