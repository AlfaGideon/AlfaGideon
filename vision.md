# АТТЕСТАТ БЕЗ РЕМНЯ - Техническое видение проекта

## Описание проекта

Комплексная образовательная платформа как Telegram Mini App для обучения с полнофункциональными интерфейсами для всех ролей пользователей: учеников, репетиторов, родителей и администраторов.

## Принципы разработки

- **KISS (Keep It Simple, Stupid)** - простота превыше всего
- **YAGNI (You Aren't Gonna Need It)** - не добавляем функций заранее
- **MVP (Minimum Viable Product)** - сначала основа, потом расширения
- **Fail Fast** - быстрое выявление проблем на раннем этапе
- **Итеративная разработка** - пошаговое улучшение

## Технологический стек

### Frontend
- **React + TypeScript** - типобезопасная разработка
- **Vite** - быстрая сборка и hot reload
- **Shadcn/ui + Radix UI** - готовые компоненты с accessibility
- **Tailwind CSS** - утилитарный CSS фреймворк
- **Zustand** - легковесное состояние клиента
- **TanStack Query** - серверное состояние и кеширование
- **Wouter** - минималистичная маршрутизация
- **Framer Motion** - плавные анимации

### Backend
- **Node.js + Express** - проверенное решение
- **TypeScript** - единый язык на всем стеке
- **WebSocket (ws)** - реальное время для чатов
- **Drizzle ORM** - типобезопасная работа с БД
- **PostgreSQL** - надежная БД для продакшена

### Интеграции
- **Telegram WebApp SDK** - нативная интеграция
- **WebRTC** - видеозвонки и конференции
- **OpenAI API** - ИИ-возможности
- **Stripe/T-Bank** - платежные системы

## Модель данных

### Основные сущности
- **Users** - пользователи с ролями (student, tutor, parent, admin)
- **Lessons** - уроки и занятия
- **Progress** - прогресс обучения
- **Games** - образовательные игры
- **Chat Messages** - система сообщений
- **Achievements** - система достижений
- **Theory Materials** - теоретические материалы
- **Video Conferences** - видеоконференции
- **Payments** - платежная система
- **Notifications** - уведомления

### Принципы структуры БД
- Минимум полей - только необходимые
- Четкие связи между сущностями
- Поддержка ролевой модели
- Масштабируемость для групповых функций

## Работа с внешними API

### OpenAI Integration
- Централизованный клиент в `server/openai.ts`
- Обработка ошибок и retry логика
- Мониторинг использования токенов

### Telegram Integration
- WebApp SDK для Mini App
- Bot API для уведомлений
- Webhook для входящих сообщений

## Мониторинг и логирование

### Структурированные логи
- Уровни: ERROR, WARN, INFO, DEBUG
- Контекст: userId, sessionId, action
- Метрики: время ответа, использование API

### Мониторинг производительности
- WebSocket соединения
- Database queries
- API response times
- Memory usage
