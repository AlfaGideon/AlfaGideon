
# 🤖 Russian Mentor - Telegram Bot

## 🎯 Описание

Полнофункциональный Telegram бот для платформы изучения русского языка с красивым интерфейсом и тремя ролевыми режимами.

## 🔐 Администратор

**Важно!** Админ панель доступна только пользователю с Telegram ID: `6240695985`

### Функции администратора:
- 👥 **Управление пользователями** - просмотр и управление всеми пользователями
- 📊 **Системная статистика** - детальная статистика платформы в реальном времени
- 📁 **Управление контентом** - модерация уроков и материалов
- ⚙️ **Системные настройки** - конфигурация платформы
- 📋 **Журнал действий** - отслеживание всех действий

## 🎓 Для студентов:
- 📚 **Уроки** - доступ к образовательному контенту
- 🎮 **Игры** - развивающие игры (память, грамматика, произношение, культурная викторина)
- 🏆 **Достижения** - система наград и прогресса
- 📊 **Прогресс** - отслеживание личного развития
- 🏅 **Таблица лидеров** - соревнования с другими студентами
- 💬 **Чат** - связь с преподавателями

## 👨‍🏫 Для преподавателей:
- 👥 **Мои студенты** - управление подопечными
- 📚 **Создание уроков** - разработка контента
- 📝 **Создание квизов** - интерактивные задания
- 📁 **Материалы** - управление учебными материалами
- 🎯 **Игра Эрудит** - специальная игра для преподавателей
- 📊 **Аналитика** - статистика студентов

## 🚀 Запуск

### 1. Быстрый запуск:
```bash
./start-telegram-bot.sh
```

### 2. Ручной запуск:
```bash
tsx bot/index.ts
```

### 3. В режиме разработки:
```bash
npm run dev:bot
```

## 📱 Команды бота

Все команды автоматически появляются в меню Telegram:

- `/start` - 🚀 Начать работу (регистрация/выбор роли)
- `/menu` - 📋 Показать главное меню
- `/reset` - 🔄 Сбросить аккаунт и выбрать роль заново
- `/help` - ❓ Показать справку по командам

## 🎨 Особенности интерфейса

- ✨ **Красивое форматирование** с HTML разметкой
- 🎯 **Роль-специфичные меню** - интерфейс адаптируется под роль пользователя
- 📊 **Интерактивная статистика** - живые данные для администраторов
- 🔄 **Простое переключение ролей** - возможность смены роли в любой момент
- 🛡️ **Защищенный доступ** - админ панель только для авторизованных пользователей

## 🔧 Техническая информация

- **База данных**: PostgreSQL (полная интеграция с веб-приложением)
- **Аутентификация**: По Telegram ID
- **Безопасность**: Проверка прав доступа для админ функций
- **Логирование**: Полные логи в `/tmp/telegram-bot.log`

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи: `tail -f /tmp/telegram-bot.log`
2. Убедитесь что токен корректен в `.env`
3. Перезапустите бота: `./start-telegram-bot.sh`
