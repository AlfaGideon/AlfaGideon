# АТТЕСТАТ БЕЗ РЕМНЯ - Telegram Bot

Telegram бот, предоставляющий полный функционал образовательной платформы "АТТЕСТАТ БЕЗ РЕМНЯ" прямо в мессенджере Telegram.

## Возможности бота

### Для студентов 🎓
- **Уроки** - Просмотр доступных уроков по сложности и категориям
- **Игры** - Доступ к интерактивным играм (память слов, грамматика, произношение, скоростное чтение, культурная викторина, Эрудит)
- **Достижения** - Просмотр полученных наград и достижений
- **Прогресс** - Отслеживание уровня, опыта, стрика и завершенных уроков
- **Таблица лидеров** - Сравнение результатов с другими студентами
- **Настройки профиля** - Просмотр данных аккаунта

### Для преподавателей 👨‍🏫
- **Студенты** - Управление назначенными студентами
- **Создание контента** - Быстрый доступ к созданию уроков и квизов
- **Материалы** - Управление теоретическими материалами
- **Игра Эрудит** - Специальная игра для преподавателей
- **Аналитика** - Статистика по студентам и их прогрессу

### Для администраторов 🛠️
- **Управление пользователями** - Администрирование всех пользователей системы
- **Системная статистика** - Общая статистика платформы
- **Управление контентом** - Модерация уроков и материалов
- **Системные настройки** - Конфигурация платформы
- **Логи действий** - Отслеживание административных действий

## Установка и настройка

### 1. Создание Telegram бота
1. Откройте Telegram и найдите бота @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Сохраните полученный токен

### 2. Настройка переменных окружения
1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Отредактируйте `.env` и добавьте ваш токен:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
   DATABASE_URL=postgresql://username:password@localhost:5432/russian_mentor
   ```

### 3. Запуск бота
```bash
# Простой запуск
./run-bot.sh

# Или напрямую через npm
npm run start:bot
```

## Команды бота

- `/start` - Начать работу с ботом / регистрация
- `/menu` - Показать главное меню
