# Настройка меню команд Telegram бота

## ✅ Что сделано:

Бот автоматически устанавливает команды в меню Telegram при запуске. Теперь в квадратном меню (рядом со скрепкой) в чате с ботом вы увидите:

- `/start` - 🚀 Начать работу с ботом
- `/menu` - 📋 Показать главное меню  
- `/reset` - 🔄 Сбросить аккаунт и выбрать роль заново
- `/help` - ❓ Показать справку по командам

## Как это работает:

1. При запуске бота вызывается функция `setupBotCommands()`
2. Команды регистрируются через Telegram Bot API методом `setMyCommands`
3. После этого они появляются в интерфейсе Telegram

## Результат:

- Стандартные команды Telegram заменены на команды вашего бота
- Пользователи видят только нужные команды для платформы изучения русского языка  
- Удобный доступ ко всем функциям бота одним нажатием

Команды обновляются автоматически каждый раз при перезапуске бота.
